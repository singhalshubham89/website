14. Lower Bound / Upper Bound

Lower bound

First index where a[i] >= target.

Upper bound

First index where a[i] > target.

int i = upper_bound(a.begin(), a.end(), target) - a.begin();

Java typically uses a custom binary-search loop.

Complexity: O(log n).

29. Dijkstra

Use only when edge weights are non-negative.

vector<long long> dist(n, LLONG_MAX);

priority_queue<
    pair<long long,int>,
    vector<pair<long long,int>>,
    greater<pair<long long,int>>
> pq;

dist[src] = 0;
pq.push({0,src});

while(!pq.empty()) {
    auto [d,u] = pq.top();
    pq.pop();

    if(d != dist[u]) continue;

    for(auto [v,w] : graph[u]) {
        if(d+w < dist[v]) {
            dist[v] = d+w;
            pq.push({dist[v],v});
        }
    }
}
long[] dist = new long[n];
Arrays.fill(dist, Long.MAX_VALUE);

PriorityQueue<long[]> pq =
    new PriorityQueue<>((a,b) -> Long.compare(a[0],b[0]));

dist[src] = 0;
pq.offer(new long[]{0,src});

while(!pq.isEmpty()) {
    long[] cur=pq.poll();
    long d=cur[0];
    int u=(int)cur[1];

    if(d != dist[u]) continue;

    for(int[] edge : graph.get(u)) {
        int v=edge[0], w=edge[1];

        if(d+w < dist[v]) {
            dist[v]=d+w;
            pq.offer(new long[]{dist[v],v});
        }
    }
}
dist = [float('inf')] * n
dist[src] = 0

pq = [(0,src)]

while pq:
    d,u = heapq.heappop(pq)

    if d != dist[u]:
        continue

    for v,w in graph[u]:
        nd = d+w

        if nd < dist[v]:
            dist[v] = nd
            heapq.heappush(pq,(nd,v))

Complexity with adjacency list + binary heap:
O((V+E) log V), commonly written O(E log V).
Space: O(V+E) including graph and heap/dist structures.

    if(!root) return;

    // preorder process

    dfs(root->left);
    dfs(root->right);
}

    if(root == null) return;

    // preorder process

    dfs(root.left);

}

    if not root:

Traversal order:

  • Preorder: node → left → right
  • Inorder: left → node → right
  • Postorder: left → right → node

Complexity: O(n) time.
Recursion space: O(h), worst case O(n), balanced tree O(log n).

36. Union Find / DSU

C++

class DSU {
    vector<int> parent, rank;

public:
    DSU(int n): parent(n), rank(n,0) {
        iota(parent.begin(), parent.end(), 0);
    }

    int find(int x) {
        if(parent[x] != x)
            parent[x] = find(parent[x]);

        return parent[x];
    }

    bool unite(int a,int b) {
        a=find(a);
        b=find(b);

        if(a==b) return false;

        if(rank[a] < rank[b])
            swap(a,b);

        parent[b]=a;

        if(rank[a] == rank[b])
            rank[a]++;

        return true;
    }
};

Java

class DSU {
    int[] parent;
    int[] rank;

    DSU(int n) {
        parent=new int[n];
        rank=new int[n];

        for(int i=0;i<n;i++)
            parent[i]=i;
    }

    int find(int x) {
        if(parent[x] != x)
            parent[x] = find(parent[x]);

        return parent[x];
    }

    boolean union(int a,int b) {
        a=find(a);
        b=find(b);

        if(a==b) return false;

        if(rank[a] < rank[b]) {
            int t=a;
            a=b;
            b=t;
        }

        parent[b]=a;

        if(rank[a] == rank[b])
            rank[a]++;

        return true;
    }
}

Python

class DSU:
    def __init__(self,n):
        self.parent=list(range(n))
        self.rank=[0]*n

    def find(self,x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])

        return self.parent[x]

    def union(self,a,b):
        a=self.find(a)
        b=self.find(b)

        if a == b:
            return False

        if self.rank[a] < self.rank[b]:
            a,b=b,a

        self.parent[b]=a

        if self.rank[a] == self.rank[b]:
            self.rank[a]+=1

        return True

With path compression + union by rank:

  • find: amortized O(α(n))
  • union: amortized O(α(n))
  • m operations: O(m α(n))
  • Space: O(n)

For interviews, treat α(n) as practically constant.

51. Language Gotchas

C++

  • unordered_map[key] creates the key if absent.
  • Prefer long long for sums that may exceed 2^31-1.
  • lower_bound / upper_bound require a sorted range.
  • priority_queue is a max heap by default.
  • Recursive DFS can overflow the stack on very deep graphs.

Java

  • Arrays use .length; strings use .length(); collections use .size().
  • Use .equals() for string/content equality, not ==.
  • Prefer ArrayDeque for stack and queue.
  • PriorityQueue is a min heap by default.
  • Use Integer.compare(a,b) instead of comparator subtraction such as a-b when overflow is possible.
  • Primitive int[] cannot directly use Collections.reverseOrder().

Python

  • Use deque.popleft() for queues; list.pop(0) is O(n).
  • heapq is a min heap; use negatives for a portable max heap.
  • Avoid [[0]*m]*n for matrices.
  • Tuple comparison and heap ordering are lexicographic.
  • Recursion depth is much lower than typical C++/Java stack limits on coding platforms.
  • // floors toward negative infinity; C++/Java integer division truncates toward zero.

54. Complexity Reasoning During Interviews

A useful way to explain complexity:

Sliding Window

Both left and right only move forward and each moves at most n times, so although there is a nested while-loop, total time is O(n).

Monotonic Stack

Every element is pushed at most once and popped at most once, so total work is O(n).

BFS / DFS

Each vertex is visited once and every edge is examined a constant number of times, giving O(V+E).

Heap Top-K

Maintain a heap of at most k items. Each insertion/removal costs O(log k), giving O(n log k).

Union Find

Path compression and union by rank make each operation amortized O(α(n)), effectively constant in practice.

DP

Count the number of unique states, then multiply by the work required for each state.

Example:

n states × O(1) transition = O(n)

n × m states × O(1) transition = O(nm)

n states × O(n) transition = O(n²)
